# HigherKey Operator OS Beta Readiness Checklist

Use this checklist before handing the app to a client or running a live demo.

## Install And Launch

- [ ] Install DMG from the latest local build.
- [ ] Open the newest DMG from `dist/`.
- [ ] Drag HigherKey Operator OS into Applications if desired.
- [ ] Launch HigherKey Operator OS.
- [ ] Confirm the version badge matches the expected build.
- [ ] Confirm the app shows Local-first and Manual upload.

## Project Setup

- [ ] Choose or create a project folder.
- [ ] Confirm the project folder is not the content inbox itself.
- [ ] Confirm the content inbox opens from the app.
- [ ] Confirm Diagnostics shows the project is usable.

## Client Workflow

- [ ] Import MP4, MOV, or M4V test footage with Import Footage.
- [ ] Run Import & Process or Process Media.
- [ ] Confirm clips appear for review.
- [ ] Approve at least one clip.
- [ ] Export social packs.
- [ ] Open the social export folder.
- [ ] Confirm captions, hashtags, titles, posting notes, manifests, and thumbnails are present where available.
- [ ] Upload manually using the prepared files.

## Support And Feedback

- [ ] Run Diagnostics if anything needs attention.
- [ ] Create a support package if reporting an issue.
- [ ] Capture client feedback locally.
- [ ] Confirm no original footage is included in the issue report by default.

## Safety Notes

HigherKey Operator OS runs locally. It does not use cloud APIs, social APIs, or direct posting APIs. Social export packs are prepared for manual upload only.
